# RAG基础

RAG 的全称是 Retrieval-Augmented Generation，即检索增强生成。它把外部知识库检索与大语言模型生成结合起来，让模型能够根据指定资料回答问题。

一个基本的 RAG 系统通常包含三个阶段。第一阶段是 Retrieval，系统把用户问题转换成向量，并从知识库中检索相似文本。第二阶段是 Augmentation，系统把检索结果和问题组合成提示词。第三阶段是 Generation，生成模型根据提示词产生答案。

RAG 可以减少模型仅依赖参数记忆造成的知识过时和事实错误，但检索到资料不代表答案一定正确。因此系统还需要相关性门槛、引用来源、自动化测试和质量评估。
